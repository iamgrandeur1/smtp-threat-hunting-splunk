# SMTP Email Traffic Analysis & Threat Hunting Using Splunk

This repository documents an SMTP threat hunting project using Splunk and Zeek SMTP logs.

The project focused on analyzing email-related network activity, identifying high-volume SMTP hosts, investigating mail domains, and monitoring email infrastructure behavior within a SOC lab environment.

---

## Technologies Used

- Splunk
- Zeek
- Kali Linux
- VirtualBox
